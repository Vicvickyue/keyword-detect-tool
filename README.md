# 文件关键词检索工具

Windows 本地离线工具：检索文本、表格和多层压缩包，输出带中文内容、定位信息和匹配次数的 PDF 报告。无需联网、无需安装 Python 或 Microsoft Excel。

**[下载 KeywordReportTool-Windows-x64.zip（约 58 MiB）](https://github.com/Vicvickyue/keyword-detect-tool/raw/refs/heads/main/downloads/KeywordReportTool-Windows-x64.zip)**

已编译的 v1.0.0 便携包包含 EXE、运行依赖、三个 Excel 词库模板、示例和使用说明。完整解压后双击 `KeywordReportTool.exe`；不需要运行源码或构建脚本。请勿单独移动 EXE，必须保留同目录的 `_internal` 文件夹。

如果直接下载链接未打开，可进入 [下载目录](downloads/README.md)，点击 ZIP 文件，再选择 GitHub 的 **Download raw file**。私有仓库需要先登录有权限的 GitHub 账号。[SHA-256 校验文件](downloads/KeywordReportTool-Windows-x64.zip.sha256)

## 快速使用

1. 解压整个 `KeywordReportTool-Windows-x64.zip`，双击 `KeywordReportTool.exe`。请保留同目录的 `_internal` 文件夹。
2. 添加待检索文件或文件夹。文件夹递归扫描，压缩包自动展开。
3. 选择三个独立 Excel 词库：Product ID、EQID、Layer_Step。
4. 选择独立的报告输出目录，点击“开始检索”。
5. 完成后点击“打开 PDF”。报告名示例：`检索报告_20261009_01.pdf`。

支持 Windows 10/11 x64。便携包包含 7-Zip 和运行依赖，无需管理员权限。
在干净 Windows 环境部署前建议用自带示例试运行。尚未使用真实业务文件验收；
`.cxv`、`.filepart` 私有格式是否可读取决于其实际内容。

## 词库维护

三个词库使用 `.xlsx` 或 `.xlsm`，读取**第一个工作表、A 列**。
A1 为表头，A2 起每行一个 ID。去除首尾空格、忽略空行、合并重复 ID。
词库中请使用文本值，公式单元格会提示错误。每次检索重新加载，不用重新打包。

- `词库模板/`：空白模板，填写后用于实际检索。
- `示例/示例词库/`：纯合成示例，不要当作生产词库。
- `示例/待检索文件/`：含普通日志、CSV、Excel、XML、五层压缩和无匹配文件。

词库路径未配置时该规则不启用，并写入报告；已配置但词库为空、损坏或不存在会阻止任务，避免误判无匹配。词库文件本身不会作为输入内容扫描。

## 规则与计数口径

| 规则 | 匹配内容 |
|---|---|
| 产品 Lot ID | A0 / AT / AL + 4 位数字，可带一个或多个点号及字母数字后缀 |
| NPW Lot ID | AC / AD / AF + 6 位数字，可带点号及字母数字后缀 |
| Product ID | Product ID Excel 词库 |
| Foup ID | APE / ANG / ANS + 5 位数字 |
| EQID | EQID Excel 词库 |
| Layer_Step | Layer_Step Excel 词库 |

`AT0004.13` 与 `AT0004.14` 是不同 ID；`A00001.S46` 保留完整后缀。
固定格式不匹配嵌在更长字母数字编号中的前缀，例如 `AC0000619` 不命中。
固定规则允许下划线作为分隔符；点号后带字母数字作为 Lot 后缀。后缀语法可按真实业务样本进一步收紧。

默认区分大小写。词库默认按完整 ID 匹配：相邻 ASCII 字母、数字、下划线或点号时不当作完整词；可在高级设置切换为包含匹配。匹配按字面文本，不把词库字符当作正则表达式。

每个文件、每条规则、每个完整 ID **统计全部出现次数，仅保留前 5 处明细**。
同一行/单元格出现三次计三次，上下文保留一份。压缩包内每个文件分别计算；同一 Excel 的全部工作表共享五处限制。一个位置命中不同规则时分别计数，总次数按规则累加。顺序为目录名称排序、压缩成员顺序、工作表顺序、行列顺序。

## 文件支持

| 类型 | 检索范围 / 定位 |
|---|---|
| TXT / LOG / XML / JSON 等文本 | 原始文本行，记录行号和完整行；XML 不执行实体解析 |
| CSV / TSV / CXV | 自动识别逗号、Tab、分号、竖线；支持引号和单元格内换行；记录号不是物理文本行号 |
| XLSX / XLSM | 全部工作表（含隐藏）、隐藏行列；记录工作表及坐标，不执行宏 |
| XLS / XLSB / ODS | 由 calamine 读取单元格值及坐标 |
| ZIP / 7Z / RAR / TAR / GZ / BZ2 / XZ | 由便携包中的 7-Zip 逐成员读取，支持混合嵌套 |
| .filepart / 错误后缀 | 优先识别文件头；完整的已支持格式可读取，不完整、损坏、私有二进制会标注失败/不支持 |

表格默认第 1 行为表头（高级设置可指定，0 表示无表头）。包括表头在内的所有单元格参与搜索。
明细保存命中列、同一行左一列及右一列的值和对应表头。首末列保留实际存在的邻列。
合并单元格仅检索实际存储值的左上单元格，不把值复制到其他单元格重复计数。
不检索图形、批注、文本框、嵌入附件或图片中的文字，也不执行 OCR。

Excel 按保存的结果值检索，不重算公式。XLSX/XLSM 会检查公式缓存缺失并标记部分完成；
XLS/XLSB/ODS 不逐项验证公式缓存，报告附带说明。数字日期按读取值转为文本，不复刻 Excel 的所有显示格式。

文本支持 UTF-8、UTF-16、GB18030 及编码检测。编码错误不静默替换为“完成”。未知编码可能需要真实样本调整。
`.cxv` 暂按分隔文本尝试读取，无法解析时标明失败。`.filepart` 是后缀而非压缩标准；仅内容可读不等于传输完整，软件无法证明普通文本传输已经结束。

## 压缩、分卷与限制

默认最大深度 10（可设为 5–30），每个压缩或归档容器算一层；`.tar.gz` 算两层。
XLSX/ODS 的内部 ZIP 容器不算业务压缩层，也不会重复搜索其内部 XML。
完整来源路径保留为 `外层.zip → 内层.7z → data.log`。

支持同目录完整的常见根层分卷（如 `.7z.001/.002`、`.zip/.z01`）；由首卷统一解读。
缺卷、加密包、坏包、重复成员路径等明确标记异常。当前不提供密码输入，不承诺修复损坏文件或自动重组私有分片。
嵌套压缩内部的分卷集合尚不支持自动重组，请先完整解包到同一目录。

默认每文件上限 2 GiB、累计解包输出上限 10 GiB、发现文件数上限 10,000、每次解包操作超时 180 秒；单文本行/CSV 单元格超过 8 Mi 字符会标记未完成。
上限可防止无限展开；解压子进程按短间隔监控，大小可能有少量瞬时超额。
表格库可能整表加载，超大 XLS/XLSB/ODS 的内存和取消响应取决于底层库；本版面向约 20 个普通文件的批次。
使用生成的临时文件名接收解包 stdout，不使用成员路径写磁盘；不跟随文件系统链接、归档链接或目录联接。

## 输出与失败状态

- PDF：任务概览、规则及词库摘要、文件清单、各关键词总数、前五处明细、失败原因。
- 同名 `.jsonl`：UTF-8 检索日志，包含结构化明细及未截断的原始内容，便于复核。
- 报告编号按输出目录、本地日期递增，01–99，超过 99 提示更换目录，不覆盖已有 PDF。
- 采用临时生成、完成后原子发布；正常退出删除锁文件。强制终止后残留 `.pdf.lock` 只会占用一个编号。
- “完成 / 未命中”和“失败 / 未知”明确区分；失败文件已观察到的次数不代表完整总数。
- 取消后保留已扫描结果，PDF 标注未完成；解析库内部某次读取可能要完成后才响应取消。
- 输入目录中的报告输出目录自动排除。输出目录不可与输入目录相同。

所有内容在本机处理；程序运行不上传文件。运行设置保存在当前用户的 Windows 设置中。

## 源码运行与构建

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe main.py
```

源码运行压缩检索需安装 7-Zip；构建会将本机 7-Zip 运行文件复制到便携包并带上许可证。

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

输出 `dist/KeywordReportTool-Windows-x64.zip`。构建脚本先运行测试，再生成 EXE、模板、示例和依赖许可。
默认 `C:\Program Files\7-Zip`，可用 `-SevenZipDirectory` 修改。构建需 Windows x64 和 Python 3.13。

命令行（源码和打包 EXE 均支持，EXE 为窗口子系统，因此不显示终端输出）：

```powershell
.venv\Scripts\python.exe main.py --scan D:\logs --output D:\reports `
  --product D:\dict\Product_ID.xlsx --eqid D:\dict\EQID.xlsx --layer D:\dict\Layer_Step.xlsx
```

退出码：0 完整扫描，2 存在不完整文件，1 任务或报告生成失败。
